# 🧠 Multi-Agent System with CrewAI

This repository contains a hands-on implementation of a **Multi-Agent System** built using [CrewAI](https://docs.crewai.com/), following the tutorial from the [Educative.io course](https://www.educative.io/courses/build-ai-agents-and-multi-agent-systems-with-crewai/building-our-first-multi-agent-system-with-crewai).

## 🚀 Overview

The project demonstrates how to build a basic Multi-Agent System in Python using CrewAI. It features a team of AI agents collaborating to complete a task through defined roles, goals, and tools.

**Core Concepts Covered:**
- Defining agent roles, backstories, and goals
- Creating tools using LangChain
- Defining tasks and assigning agents
- Structuring a crew and executing collaborative tasks

## 🛠️ Tech Stack

- **Python** 🐍
- **CrewAI** 🤖
- **LangChain**
- **OpenAI API** or other LLM providers
- **Environment variables** for API key management
